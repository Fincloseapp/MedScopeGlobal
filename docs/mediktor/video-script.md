# MeDiktor — video script (60–90 s)

**[0–8 s]** Lékař u PC — klávesnice, únava, fronta. Hlas: „Zápis po každém pacientovi bere čas, který patří péči.“

**[8–20 s]** Stejný lékař zvedne telefon. Diktuje / vede rozhovor. Hlas: „Diktujte. Nebo nahrajte konzultaci s pacientem či pacientkou.“

**[20–40 s]** UI MeDiktor — text se skládá. Hlas: „MeDiktor připraví odbornou anamnézu. Vy zkontrolujete a uložíte.“

**[40–55 s]** Úsměv, více očního kontaktu s pacientem. Hlas: „Rychlejší práce. Méně psaní. Více péče.“

**[55–75 s]** CTA na obrazovce: Stáhnout aplikaci · Vyzkoušet zdarma · medscopeglobal.com/mediktor
Hlas: „MeDiktor od MedScopeGlobal. Pro lékaře.“

**Poznámka:** Uvést, že jde o asistenta — lékař schvaluje finální zápis; při nahrávce rozhovoru informovat pacienta.
